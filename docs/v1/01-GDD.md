# 《飞行小八戒》V1 游戏设计文档（GDD）

## 1. 产品概述

《飞行小八戒》是一款竖屏、单指操作、无限挑战型微信小游戏。玩家操控不会真正飞行的八戒，用两只大耳朵奋力维持高度，在天宫与云海之间穿越成对出现的障碍物，追求更高分数。

一句话体验：**连续点击让八戒扑扇大耳朵向上跃飞，停止点击后自然下落，在轻松滑稽的东方云端世界里险中求生。**

## 2. 设计支柱

1. **一秒上手**：全程只需要连续点击和停止点击。
2. **手感可控**：飞行有惯性，但不能出现明显输入延迟或无法挽救的漂移。
3. **公平可读**：所有危险都有清楚轮廓；动态危险有规律或预警。
4. **八戒有戏**：耳朵、衣摆、表情和受击反应共同表达笨拙飞行。
5. **短局可重开**：失败后两次以内操作即可重新开始。

## 3. 目标用户与单局节奏

- 面向喜欢轻量反应游戏、碎片时间娱乐和东方神话题材的微信用户。
- 单局常见时长目标：新手 `20～60 秒`，熟练玩家 `2～5 分钟`。
- 首次进入后 `5 秒` 内理解操作，`10 秒` 内开始第一局。

## 4. 核心循环

1. 首页看到八戒悬浮待机及“点击屏幕开始”提示。
2. 首次点击后进入游戏，八戒获得一次向上冲量。
3. 玩家通过连续点击维持高度，停止点击后下降。
4. 穿过一组上下障碍物后得 1 分。
5. 随分数提高，速度、通道尺寸和动态组合逐档变化。
6. 碰撞后结算本局分数和历史最高分。
7. 点击“再来一次”立即重开。

## 5. 操作与飞行规则

- `Pointer Down / Touch Start`：仅在按下边沿触发一次向上冲量。
- 持续按住不重复触发；必须抬起后再次点击，才能获得下一次冲量。
- `Pointer Up / Touch End / Touch Cancel`：不施加额外动力；八戒继续受重力影响。
- 每次点击将垂直速度设为统一的向上速度初值，保证点击反馈一致；停止点击后自然下落。
- 设置极短的重复点击保护，只过滤同一物理触摸产生的重复事件，不吞掉正常快速连点。
- 上升速度和下降速度都设上限，避免失控。
- 八戒固定在屏幕横向约 `30%` 的位置；背景和障碍向左移动。
- 上升时身体轻微抬头，下落时逐渐低头；旋转只负责表现，不改变操作逻辑。
- 触碰屏幕顶部、底部危险边界或任意障碍物即失败。

## 6. 游戏状态

| 状态 | 行为 |
| --- | --- |
| Boot | 加载首屏必需资源和本地最高分 |
| Home | 八戒待机、显示标题和开始提示 |
| Ready | 可选的极短起步缓冲，首按即开始 |
| Playing | 接收输入、移动、生成障碍、计分 |
| Paused | 停止游戏时间与输入，保留场景 |
| GameOver | 播放撞击反馈并展示结算 |

切后台、音频中断或微信生命周期暂停时必须进入暂停；回到前台不得自动继续导致死亡。

## 7. 计分与失败

- 每组上下障碍共享一个不可见计分门。
- 八戒从左到右意义上穿过计分门时加 1 分，每组只能计分一次。
- 最高分存储在本地；存储失败不能阻塞游戏。
- 碰撞后立即停止计分和障碍生成，短暂播放受击反馈，再进入结算。
- 结算展示：本局分数、历史最高分、“再来一次”、返回首页。

## 8. 障碍物系统

### 8.1 第一版资产

地面：山峰、石柱（均可独立上下移动）、火球（动态）。

天空：乌云（独立上下移动）、雷电（动态开关）、风火轮（旋转，可小幅往返）。

上下两两组合共 9 种。组合只是素材配对，实际生成还受安全规则和难度表约束。

### 8.2 安全生成原则

- 只从预设的小、中、大尺寸档位选择，不进行无限制随机缩放。
- 上下障碍之间必须保留可穿越通道。
- 连续通道中心高度变化有上限，禁止突然从最低跳到最高。
- 动态障碍物的最大位移也必须计入最小安全通道计算。
- 高危险组合“雷电 + 火球”不在新手阶段生成。
- 两侧动态障碍不能同时向通道中心运动并封死路线。
- 雷电必须先预警再生效；火球和风火轮的运动轨迹必须可预测。
- 上下障碍从第一组开始各自使用独立振幅、周期和相位，通道中心与高度会持续变化。
- 实时有效通道不得小于 300 px；低于安全值前，两侧分别向外修正一半差额。
- 独立移动通道可叠加火球、雷电或风火轮，动态障碍按实时通道中心和宽度重新定位。
- 通道完整进入画面后先显示至少 0.80 s 的双轨迹提示，再开始独立运动。
- 障碍的实际碰撞体略小于危险视觉轮廓，避免“看起来没碰却死亡”。

## 9. 难度曲线

难度使用分段配置，不按每一分连续改变：

- 入门段：以静态组合为主，通道宽、移动慢。
- 熟悉段：加入单个动态障碍，通道略缩小。
- 挑战段：提高动态组合权重和移动速度。
- 高分段：保持可解，主要考验节奏稳定性，不生成理论无解组合。

详细初值见 [04-BALANCE-CONFIG.md](./04-BALANCE-CONFIG.md)。

## 10. 角色表现

| 状态 | 动画与表情 |
| --- | --- |
| Idle | 上下浮动、慢扇耳朵、眨眼或擦汗 |
| FlyUp | 每次有效点击从首帧短播；正常上升和轻微滑翔保持起飞末帧 |
| Fall | 仅在明显且持续的真实下落时播放，耳朵松开、身体低头、双手慌乱 |
| Hit | 表情挤压、帽子歪斜、短促后坐 |
| Dead | `Hit` 后衔接死亡动画并保持最后一帧，关闭碰撞后旋转加速掉出屏幕，离屏后进入结算 |

## 11. 场景与镜头

- 默认竖屏 `9:16`，设计分辨率建议 `750 × 1334`。
- 镜头固定，不做主动追踪；八戒只在纵向移动。
- 四层视差：天空与云海、远处天宫/仙山、中景浮岛/宫殿、近景云丝。
- 背景元素不能穿过核心通道形成假障碍。
- 受击可有极轻微屏幕震动，时长短、幅度小。

## 12. 音频与反馈

- 每次点击起飞：播放一次柔软、短促的耳朵扑扇声。
- 停止点击下落：弱风声随速度增强。
- 得分：清脆而轻盈的提示音。
- 雷电、火球、风火轮分别有可辨识音色。
- 撞击：短促低频冲击 + 八戒滑稽叫声，避免刺耳。
- 背景音乐：轻快东方器乐与空气感，不持续堆叠高频。

## 13. 界面与流程

- 首页：标题、八戒待机、开始提示、最高分、音频开关。
- 游戏中：当前分数、暂停按钮；不放多余功能。
- 暂停：继续、重新开始、返回首页。
- 结算：本局分数、最高分、再来一次、返回首页。
- 所有交互适配安全区，按钮触控区域大于视觉图标。

## 14. V1 范围

### 必须完成

- 完整开始—游玩—失败—重开闭环。
- 八戒五类状态表现。
- 三种地面与三种天空障碍、九种配对。
- 受约束随机生成、对象池、碰撞与计分。
- 四层天宫背景和基础 UI。
- 本地最高分、音频开关、前后台暂停。
- 微信开发者工具和至少一台真机可运行。

### 明确不做

- 广告、付费、复活、皮肤、角色养成。
- 道具、任务、成就、关卡地图。
- 好友排行、开放数据域、云存档、账号体系。
- 多角色、多主题场景、剧情和新手长教程。

## 15. 成功标准

- 新玩家无需文字说明即可在首次游玩中理解“连续点击上升、停止点击下落”。
- 连续试玩 10 局不出现无解障碍组合。
- 输入、碰撞与得分没有明显延迟、重复或漏判。
- 中档微信真机目标保持稳定流畅，连续运行无明显内存增长。
- 失败后能在 2 秒左右进入结算，并可快速重开。
