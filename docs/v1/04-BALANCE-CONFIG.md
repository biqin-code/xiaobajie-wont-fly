# 《飞行小八戒》V1 数值与生成规则

## 1. 文档性质

以下数值是首个可玩原型的起始值，用来尽快得到统一手感，不代表最终平衡。每轮试玩一次只调整一类变量，并记录结果。

坐标以 `750 × 1334` 设计分辨率下的逻辑像素为基准；实际节点适配由 Canvas 完成。

## 2. 飞行初值

| 参数 | 初值 | 说明 |
| --- | ---: | --- |
| `gravity` | `-1580 px/s²` | M5 调优值；没有点击冲量时持续生效的向下加速度 |
| `flapVelocity` | `+405 px/s` | M5 调优值；每次有效点击后设置的向上速度 |
| `minFlapInterval` | `0.09 s` | 只防止重复事件，不限制正常连续点击 |
| `maxRiseSpeed` | `+535 px/s` | 最大上升速度 |
| `maxFallSpeed` | `-760 px/s` | 最大下降速度 |
| `startVelocityY` | `0 px/s` | 开局速度 |
| `maxDeltaTime` | `0.033 s` | 防止单帧过大导致穿透 |
| `riseTilt` | `+14°` | 最大上仰表现角 |
| `fallTilt` | `-34°` | 最大下俯表现角 |
| `tiltSmoothTime` | `0.10 s` | 倾角平滑时间 |

旧的 `holdAcceleration` 持续加速度模型已被玩法 PIVOT 废止。新模型中每次有效点击将 `velocityY` 设置为 `flapVelocity`，其余时间仅应用重力。点击模型已于 2026-09-01 接入代码，数值仍需真人试玩确认。

## 3. 玩家与边界

| 参数 | 初值 |
| --- | ---: |
| 玩家水平位置 | 屏幕宽度 `30%` |
| 玩家视觉参考尺寸 | 约 `150 × 135 px` |
| 核心碰撞体参考尺寸 | 约 `92 × 84 px` |
| 顶部安全边距 | `90 px` |
| 底部安全边距 | `110 px` |

耳朵最外缘默认不全部纳入死亡碰撞体；最终碰撞大小必须以真机视觉公平性校准。

## 4. 难度档

| 档位 | 分数 | 障碍速度 | 通道高度 | 水平间距 | 动态组合权重 |
| --- | --- | ---: | ---: | ---: | ---: |
| D0 入门 | `0～9` | `176 px/s` | `420～450 px` | `430～470 px` | `48%` |
| D1 熟悉 | `10～23` | `190 px/s` | `400～430 px` | `410～450 px` | `60%` |
| D2 挑战 | `24～41` | `204 px/s` | `380～410 px` | `395～435 px` | `72%` |
| D3 高分 | `42+` | `218 px/s` | `360～395 px` | `380～420 px` | `82%` |

“通道高度”是考虑动态障碍最大位移后的最窄有效空间，不是两张贴图锚点之间的距离。

## 5. 通道生成

- 通道中心允许区域：扣除上下安全边距及障碍视觉余量后的可用高度。
- 相邻通道中心最大变化：D0 `180 px`、D1 `210 px`、D2 `230 px`、D3 `250 px`。
- 第一组障碍必须接近屏幕纵向中心，且使用静态组合。
- 同一种上方或下方障碍连续出现不超过 2 次。
- 动态 + 动态组合后至少插入 1 组低风险组合。
- 安全验证最多重新采样 8 次，仍失败则使用“乌云 + 山峰”的标准安全组合。

## 6. 组合权重初值

基础权重相同，但按难度应用以下规则：

- D0：山峰、石柱、乌云为主；火球/雷电/移动风火轮低概率单侧出现。
- D1：允许一个动态障碍正常出现。
- D2：允许动态 + 动态，但禁用同时向中心夹击的相位。
- D3：提高雷电、火球、移动风火轮权重，不进一步无限缩小通道。
- “雷电 + 火球”从 D2 开始出现，且连续两组内不得再次出现。

## 7. 动态障碍初值

| 障碍 | 参数 | 初值 |
| --- | --- | ---: |
| 火球 | 往返幅度 | `45 px` |
| 火球 | 周期 | `1.8 s` |
| 雷电 | 预警时间 | `0.70 s` |
| 雷电 | 生效时间 | `0.32 s` |
| 雷电 | 冷却时间 | `1.10 s` |
| 风火轮 | 往返幅度 | `35 px` |
| 风火轮 | 往返周期 | `2.2 s` |
| 风火轮 | 旋转周期 | `0.85 s/圈` |
| 上下独立移动通道 | 预告停留 | `0.80 s` |
| 上侧障碍 | 振幅 / 周期 | `48～60 px / 2.5～2.9 s` |
| 下侧障碍 | 振幅 / 周期 | `48～60 px / 3.1～3.5 s` |
| 上下独立移动通道 | 最小有效高度 | `300 px` |

动态位移方向默认远离通道中心或横向平行；如果进入通道，安全计算必须扣除完整位移幅度。

### 7.1 上下独立移动规则

- 从第一组开始，上下障碍分别生成振幅、周期和初始相位。
- 两侧原始正弦轨迹互不读取对方状态。
- 每帧计算 `baseGap + topOffset - bottomOffset`；小于 300 px 时，两侧各承担一半向外修正。
- 生成时分别以最大上侧振幅和最大下侧振幅检查顶底边界。
- 火球、雷电和风火轮依据实时有效通道中心与高度定位。
- 雷电仍完整经历预警，只有 Active 状态开启碰撞。
- 动态障碍最内侧不得进入 240 px 中央安全走廊。

## 8. 反馈初值

| 参数 | 初值 |
| --- | ---: |
| 得分数字弹跳 | `0.16 s` |
| 受击停顿 | `0.055 s` |
| 受击震屏 | 约 `0.15 s` 衰减，最大偏移约 `9 × 6 px` |
| 死亡到结算延迟 | `0.8 s` |
| 点击重开保护 | `0.25 s` |

## 9. 调参顺序

1. 只用静态障碍，确定单次点击冲量与重力的配合。
2. 固定速度，确定新手通道高度和水平间距。
3. 加入难度档速度变化。
4. 分别验证火球、雷电、风火轮。
5. 最后开放动态组合和权重随机。

不要同时修改重力、推力、障碍速度和通道高度，否则无法判断手感变化来自哪个参数。
