# M4：正式美术与界面接入

## 完成范围

- 背景最终升级为 V3 单幅统一绘景：不再叠加 V2 透明图层，彻底消除矩形块和拼凑边界；整图采用约 10 秒周期的 `30×16 px` 椭圆漂移与轻微呼吸缩放，使云层和天宫相对玩法主体产生肉眼可见的悬浮感。
- GameplayRoot 配置 `750 × 1334` 矩形 Mask，统一裁剪背景、障碍、玩家、特效和 UI，横屏预览时障碍也不会溢出游戏画面。
- 八戒 AnimationClip：`bajie_idle`、`bajie_fly_up`、`bajie_fall`、`bajie_hit`、`bajie_dead`。循环动画采用 6/4 帧完整序列，受击后自动衔接死亡。
- 正式特效：上升风线、得分闪光、6 帧碰撞云；M3 已接入的火球循环动画和雷电预警/生效动画继续沿用。
- 正式界面：首页、游戏 HUD、暂停遮罩、结算面板，标题统一为“飞行小八戒”。
- 首页直接展示实际玩家八戒，并将开始面板下移避免遮挡；点击开始后继续操控同一个玩家节点，不创建重复角色。
- 首页取消“点击屏幕开始”云纹底板，标题、角色和引导文字直接叠加在天宫背景上。
- 首页进一步移除标语、开始提示和操作说明，仅保留图片标题与实际玩家八戒；全屏点击仍可直接开始。
- 实际玩家八戒在首页水平居中显示于标题正下方；首次点击后用 0.24 秒平滑移动到左侧飞行位置，全程不替换节点。
- 动画状态按动作语义触发：每次有效点击从首帧短播 `fly_up`，速度转负才循环 `fall`，碰撞短播 `hit` 后衔接 `dead`。
- 正常滑翔继续保持 `fly_up` 末帧；仅当下降速度不高于 `-260 px/s` 且持续至少 `0.16 s` 才进入 `fall`，避免两次点击间短暂下降造成表情闪烁。
- 碰撞后立即停用障碍、碰撞、计分和重开输入；短播 `hit` 后衔接 `dead` 并保持死亡末帧，以 `-2100 px/s²` 独立重力旋转掉出底部。离屏后显示结算，最长等待 `1.5 s`。
- UI 安全区：关键按钮和分数位于 750×1334 设计分辨率的左右 36 px、顶部 50 px 以上安全范围内。
- 九宫格：云纹、玉石、木牌和玉石按钮均配置保护边距，运行时使用 `Sprite.Type.SLICED`。
- Auto Atlas：UI、八戒、特效分别独立打包，避免背景大图进入动态图集。
- 纹理策略：透明角色/UI/特效保留 PNG 无损 Alpha；四张 750×1334 背景保持独立纹理，不参与 Atlas；微信小游戏发布构建优先使用平台支持的压缩纹理，首版回退 PNG，避免机型兼容导致黑块。
- 碰撞体：八戒视觉尺寸 168×152，圆形碰撞半径 42（直径 84），主动留出耳朵和动作外沿容错。
