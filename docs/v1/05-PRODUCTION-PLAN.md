# 《飞行小八戒》V1 制作计划

## 1. 制作原则

- 先证明操作好玩，再投入正式美术。
- 每个里程碑都交付可运行版本，不以“脚本写完”代替完成。
- 需求新增默认进入 V2 候选，只有明确替换或阻塞 V1 的内容才改当前范围。
- 所有高风险平台问题提前在微信真机验证，不留到最后一天。

## 2. 里程碑

### M0：工程与灰盒基线

交付：

- 锁定 Cocos Creator 3.8 LTS 具体补丁版本。
- 建立目录、场景、代码规范与配置入口。
- 微信小游戏空包可构建并在开发者工具运行。
- 竖屏、安全区和前后台生命周期验证完成。

退出条件：编辑器预览和微信开发者工具均能进入空白 Game 场景。

### M1：核心飞行原型

交付：

- 按 [00-PROTOTYPE-BRIEF.md](./00-PROTOTYPE-BRIEF.md) 在独立 `prototypes/flight-feel/` 建立一次性灰盒 Spike。
- 灰盒八戒、连续点击获得向上冲量、停止点击后下降。
- 顶底边界、静态障碍、死亡和快速重开。
- 固定障碍序列用于手感验证。

退出条件：按 Brief 得到 KEEP / REFACTOR / PIVOT 决策；不加入随机和正式美术掩盖问题。KEEP 后在正式工程重写，不把一次性 Spike 直接升级为生产代码。

### M2：完整玩法闭环

交付：

- 首页、Playing、暂停、结算状态机。
- 计分、最高分、对象池和背景循环。
- 三种地面、三种天空障碍的临时资源。
- 受约束随机与四档难度。
- 三种动态障碍行为。

退出条件：可连续玩 10 分钟，无无解组合、重复计分和状态错乱。

当前进度（2026-09-01）：

- [x] 7 组上下障碍节点预热为对象池，离屏后回收到队尾复用。
- [x] 首批接入山峰、石柱、乌云三类资源及 S/M/L 尺寸。
- [x] 使用独立种子随机生成通道高度、间距、宽度与地面障碍类型。
- [x] 通道生成后执行边界修正，相邻中心最大变化按难度限制为 55/70/85/95 px。
- [x] 穿越单次计分，碰撞死亡，重开时重置分数、对象池和随机序列。
- [x] 分数达到 8/20/40 时逐档提高速度并缩小安全通道与间距。
- [x] 接入火球、雷电、风火轮及动态行为（M3）。
- [ ] 完成微信真机连续 10 分钟人工试玩。

### M3：动态障碍

交付：

- 火球往返运动与 6 帧循环动画。
- 雷电“预警—生效—结束”有限状态机。
- 风火轮旋转与有限轨迹。
- 动态碰撞按状态启停，静态与动态组合受安全约束。

退出条件：预警清楚，中央安全走廊始终成立，不出现连续动态夹击。

- [x] 三类动态障碍复用 M2 的 7 组对象池。
- [x] 雷电预警 0.70 s、生效 0.32 s、结束/冷却 1.10 s。
- [x] 前两组强制静态；动态组后至少插入一组静态组合。
- [x] 中央保留 240 px 动态安全走廊。
- [x] 100 个种子共 100,000 组自动约束测试通过。
- [ ] 完成网页与微信真机 10 分钟人工试玩。
- [x] 上下障碍从第一组开始独立上下移动，振幅、周期和相位分别生成。
- [x] 增加 0.80 s 双轨迹预告、300 px 实时安全钳制及动态障碍跟随。

### M4：正式美术与界面

交付：

- 八戒全状态动画。
- 天宫四层背景。
- 六类障碍正式素材及必要变体。
- 首页、HUD、暂停、结算 UI。

退出条件：所有素材通过真机尺寸、碰撞可读性和授权检查。

### M5：手感、音频与游戏反馈

交付：

- 上升、下落和死亡动作调优。
- 得分弹跳、闪光、撞击停顿、轻微震屏和云团反馈。
- BGM、得分和碰撞音效；点击扑扇与雷电只保留视觉反馈。
- Master/Music/SFX 音量分组与前后台恢复。
- 难度曲线与障碍节奏调整。

退出条件：连续游玩反馈明确，不过度晃动或吵闹；Web 构建通过，微信真机试听和十局回归完成。

实现记录见 [14-M5-FEEL-AUDIO-FEEDBACK.md](./14-M5-FEEL-AUDIO-FEEDBACK.md)。

### M6：微信优化与候选发布版

交付：

- 包体、纹理、合图、内存和帧率优化。
- 多比例设备适配。
- 前后台、音频中断、触摸取消、长时间运行测试。
- 完整回归和发布检查表。

退出条件：满足 [06-QA-ACCEPTANCE.md](./06-QA-ACCEPTANCE.md) 的阻塞级验收项。

## 3. 推荐开发顺序

1. `GameFlow`、配置与输入。
2. `PlayerFlight` 与灰盒碰撞。
3. 固定静态障碍和计分门。
4. 对象池与循环生成。
5. 安全随机和难度档。
6. 火球、雷电、风火轮。
7. UI、本地存储、暂停和重开。
8. 背景视差、正式动画与音频。
9. 微信真机优化与回归。
