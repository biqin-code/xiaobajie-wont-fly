# M5：手感、音频与游戏反馈实现记录

## 1. 阶段目标

让核心循环从“功能可用”升级为反馈清楚、连续游玩不过度晃动或吵闹的版本。本阶段只做轻量反馈，不改变碰撞公平性和安全通道约束。

## 2. 已实现内容

- 飞行参数调整为：重力 `-1580 px/s²`、点击速度 `405 px/s`、最大上升 `535 px/s`、最大下降 `-760 px/s`。
- 上升倾角 `14°`、下降倾角 `-34°`、倾角平滑 `0.10 s`；有效点击触发约 `0.14 s` 的视觉挤压回弹，碰撞体不缩放。
- 撞击后先进行 `0.055 s` 视觉停顿，再播放撞击、死亡和掉落流程；死亡面板仍等待掉落完成后出现。
- 得分数字采用 `1.34 × 0.82` 起始形变并以 Back Out 在 `0.18 s` 内恢复，同时播放星光和低强度全屏暖闪。
- 撞击反馈包含云团序列、约 `0.10 s` 暖闪和最大约 `9 × 6 px` 的衰减震屏；震屏只作用于玩法视觉根节点，不修改玩家或障碍碰撞坐标。
- 加入原创轻量 WAV；当前运行时只启用天宫背景音乐、得分与碰撞音效。
- 音量逻辑分为 Master、Music、SFX；当前基线为 Master `-3 dB`、Music `-10 dB`、SFX `-5 dB`，单事件再使用局部增益。
- 首次起飞后启动 BGM；暂停、撞击和切后台时暂停，重开停止并等待下一次起飞，返回前台不会叠加新 BGM。
- 点击扑扇与雷电状态保持无声，只通过角色动作、预警画面和高亮表现反馈，避免高频音效干扰连续操作。
- 难度档调整为分数 `0 / 10 / 24 / 42` 四档，障碍速度 `176 / 190 / 204 / 218 px/s`，动态权重 `48% / 60% / 72% / 82%`，难度提升更平滑。

## 3. 音频文件

```text
assets/resources/audio/
├── music/
│   ├── bgm_journey_clouds_lyrical.wav（当前运行优美版）
│   ├── bgm_journey_clouds_smooth.wav（平滑版，保留追溯）
│   ├── bgm_journey_clouds_original.wav（首版原创音乐，保留追溯）
│   └── bgm_tiangong_breeze.wav（早期临时音乐，保留追溯）
└── sfx/
    ├── sfx_ear_flap.wav
    ├── sfx_score.wav
    ├── sfx_impact.wav
    ├── sfx_lightning_warning.wav
    └── sfx_lightning_strike.wav
```

这些文件为项目内程序化合成的原创首版音频，无第三方授权依赖。`sfx_ear_flap.wav`、`sfx_lightning_warning.wav` 和 `sfx_lightning_strike.wav` 仅作版本追溯保留，当前代码不加载、不播放。当前 BGM 为 `bgm_journey_clouds_lyrical.wav`：约 21.33 秒、90 BPM、D 大调五声音阶。优美版保留原创主题动机，重新组织为更长的呼吸式主旋律和低音区应答，加入缓慢弦乐式和声、稀疏云铃与仅在乐句开头出现的低鼓；通过双重低通和循环空间尾音降低电子颗粒感，峰值保留在约 `0.64`，避免遮蔽得分和撞击音效。旋律不引用《西游记》影视或游戏配乐。发布前仍需在手机扬声器、耳机和微信真机上复核响度、循环接缝与压缩格式；当前 WAV 后续可转为适合微信小游戏的压缩格式。

## 4. 反馈等级

| 事件 | 等级 | 反馈 |
| --- | --- | --- |
| 有效点击 | 小 | 无音效；角色短促挤压回弹 |
| 得分 | 中 | 数字弹跳、星光、轻闪、得分音 |
| 雷电预警 | 中 | 无音效；黄色预警画面 |
| 雷电生效 | 中 | 无音效；高亮雷电画面 |
| 撞击死亡 | 大 | 55ms 停顿、云团、暖闪、轻微衰减震屏、碰撞音 |
