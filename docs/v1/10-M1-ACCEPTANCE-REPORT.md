# 《飞行小八戒》M1 核心飞行原型验收报告

> **历史报告 / 已废止玩法：** 本报告测试的是“长按上升、松开下降”。2026-09-01 老板因体验不佳决定 PIVOT 为“连续点击冲量、停止点击下落”。旧数据仅用于追溯，不代表新玩法已验收；点击版本代码现已完成。

## 1. 验收范围

本报告覆盖固定灰盒原型的 `M1-1 → M1-6`，不包含随机障碍、正式美术、最高分存储、微信真机性能和发布验收。

## 2. 阶段结果

| 阶段 | 结果 | 证据 |
| --- | --- | --- |
| M1-1 场景与节点骨架 | 通过 | `Game.scene` 包含背景、玩法、障碍、玩家、特效和 UI 根节点 |
| M1-2 基础飞行输入 | 通过 | 长按上升、松开下降，鼠标和多点触摸统一为持续飞行动作 |
| M1-2.1 可视化试玩面板 | 通过 | 标题、操作提示、飞行遥测、FPS 和参数显示 |
| M1-3 边界与调试工具 | 通过 | 顶底边界、圆形碰撞体、参数仓库和实时调参 |
| M1-4 固定障碍测试场 | 通过 | 8 组固定通道确定循环，无随机调用 |
| M1-5 死亡、计分与重开 | 通过 | 单门单次计分、碰撞死亡、点击重开、完整单局重置 |
| M1-6 回归与首轮调参 | 有条件通过 | 自动回归通过；仍需 3 名外部玩家完成 KEEP 门槛 |

## 3. 输入与生命周期回归

| 检查项 | 结果 | 说明 |
| --- | --- | --- |
| 长按 | 通过 | 持续使用净上升加速度，速度受 `maxRiseSpeed` 限制 |
| 松开 | 通过 | 立即切换到重力，速度受 `maxFallSpeed` 限制 |
| 触摸取消 | 通过 | `TOUCH_CANCEL` 与 `TOUCH_END` 共用释放处理，不会粘住上升状态 |
| 多点触摸 | 通过 | 使用触摸 ID 集合，最后一个触点结束后释放 |
| 暂停 | 通过 | `P` 键暂停/继续，玩家、障碍和计分同时停止 |
| 切后台 | 通过 | `EVENT_HIDE` 清空输入并自动暂停 |
| 回到前台 | 通过 | 保持暂停，下一次点击主动继续 |
| 死亡重开 | 通过 | 先释放、再点击；玩家、障碍、分数和计分标记全部复位 |
| 大帧间隔 | 通过 | 飞行最大使用 `0.033s`，障碍最大使用 `0.05s` |

## 4. 十局单变量内部测试

统一条件：`60 FPS`、固定 8 门、障碍速度 `185 px/s`、同一反馈控制策略。每局只改变一个参数；T01 为基线。此测试验证确定性和参数敏感度，不替代真人手感测试。

| 局 | 唯一变量 | 值 | 通过门数 | 结果 | 上升峰值 | 下降峰值 | 按住占比 |
| --- | --- | ---: | ---: | --- | ---: | ---: | ---: |
| T01 | 基线 | - | 8 | PASS | 360 | -322 | 59% |
| T02 | `gravity` | -1700 | 8 | PASS | 324 | -296 | 58% |
| T03 | `gravity` | -1600 | 8 | PASS | 329 | -291 | 56% |
| T04 | `gravity` | -1900 | 8 | PASS | 327 | -348 | 60% |
| T05 | `holdAcceleration` | 1150 | 8 | PASS | 330 | -295 | 61% |
| T06 | `holdAcceleration` | 1350 | 8 | PASS | 293 | -263 | 57% |
| T07 | `holdAcceleration` | 1450 | 8 | PASS | 292 | -368 | 56% |
| T08 | `maxRiseSpeed` | 500 | 8 | PASS | 360 | -322 | 59% |
| T09 | `maxFallSpeed` | -760 | 8 | PASS | 360 | -322 | 59% |
| T10 | `maxFallSpeed` | -900 | 8 | PASS | 360 | -322 | 59% |

结论：放宽后的通道没有无解组合。首轮只采纳 `gravity: -1800 → -1700 px/s²`，降低松手后的下坠突兀感；其他飞行参数保持基线。

## 5. 缺陷与修复

| 编号 | 级别 | 问题 | 处理 |
| --- | --- | --- | --- |
| M1-R01 | P1 | Web 构建错误启动空的 `Boot.scene`，表现为黑屏 | 构建固定使用 `Game.scene` UUID |
| M1-R02 | P1 | 原型没有明确暂停与前后台恢复状态 | 已加入暂停、后台自动暂停和点击继续 |
| M1-R03 | P2 | 计分显示不醒目 | 已加入右上计分板，并在调试 HUD 同步分数 |
| M1-R04 | P2 | 相邻通道中心高度差过大 | 中心压缩到 `-20～55px`，通道扩大到 `400～420px` |

## 6. 决策

**历史决策：REFACTOR；当前最新决策：PIVOT 到连续点击冲量。**

旧工程稳定性回归曾支持保留“长按上升、松开下降”，但老板实际试玩后否决其体验，因此该结论被更高优先级的真人反馈覆盖。

下一步重新执行点击版本的 M1-6 十局单变量调参和 3 人盲测。
