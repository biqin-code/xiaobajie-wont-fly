# 《飞行小八戒》V1 美术与动画规范

## 1. 风格声明

目标不是复制某位在世艺术家或某个动画工作室的具体画风，而是形成原创的：

> 东方神话 × 温暖手绘动画电影感 × 自然主义云端奇幻 × 轻喜剧

关键词：清澈、温暖、柔和线条、水彩肌理、赛璐璐明暗、空气透视、富有生命感、危险但不恐怖。

## 2. 视觉优先级

1. 八戒的轮廓和表情。
2. 可通过通道与危险边界。
3. 动态障碍的预警状态。
4. 天宫世界观与空间层次。
5. 纯装饰细节。

任何装饰都不能破坏前三级可读性。

## 3. 色彩基线

| 用途 | 建议色 |
| --- | --- |
| 天空蓝 | `#168BE8` |
| 云朵暖白 | `#F5F1DD` |
| 天宫金 | `#E8B84A` |
| 宫墙红 | `#B94A3D` |
| 山石暖黄 | `#C98A49` |
| 植被青绿 | `#5E8737` |
| 八戒衣服蓝 | `#244F73` |
| 火焰橙红 | `#EF643C` |
| 雷云紫灰 | `#55516D` |

色值是配色锚点，不是纯色填充要求；正式素材应加入克制的纸感、水彩晕染和笔触变化。

## 4. 八戒造型

- 圆润短胖，头身比例约 `1:1.2`。
- 大耳朵是首要识别点，展开宽度可接近身体宽度的两倍。
- 粉色皮肤、桃红耳内、深蓝短袍、棕红围巾/腰带。
- 小帽子强化神话身份，但避免细碎挂件。
- 性格是“努力、嘴硬、有点慌”，不是英勇无畏的飞行高手。
- 轮廓在缩小到实际游戏尺寸时仍要一眼可辨。

## 5. 角色动画清单

| 动画 | 建议帧数/方式 | 关键表现 |
| --- | --- | --- |
| Idle | 6～10 帧循环 + 程序浮动 | 慢扇耳朵、眨眼、围巾摆动 |
| FlyUp | 6～8 帧短播，可被再次点击重触发 | 每次点击耳朵快速下拍、脸颊用力、身体抬头 |
| Fall | 4～6 帧循环 | 耳朵松开、双手慌乱、衣摆上扬 |
| Hit | 4～6 帧一次性 | 帽子歪、脸部挤压、短暂后坐 |
| Dead | 程序下坠 + 4～6 帧 | 落入云团或滑稽失衡 |

逐帧动画负责耳朵、衣物和表情；程序负责整体位置、倾角、轻微缩放和受击反馈。

## 6. 天宫背景

### V2 明亮浮空天宫（当前运行版本）

- 天空使用高明度蓝青渐变、奶白与淡粉云缘，整体保持温暖通透。
- 灰白悬浮仙山搭配低饱和青绿色琉璃瓦宫殿，建筑集中在画面两侧和远景。
- 中央至少 `60%` 宽度保持低对比、低细节，不能让背景轮廓形成“假障碍”。
- 四层均为 `750 × 1334`：不透明天空、远景云海、中景天宫、近景云层。
- V2 竖屏构图不允许横向复制拼接。四层使用单张全屏图和 `1.14` 倍超扫；远/中/近景分别进行 `16/28/40 px` 横向漂移及 `4/7/11 px` 上下浮动，频率逐层提升。近景透明度限制为 `165/255`，保证有飘动感、无接缝且障碍优先可读。
- 禁止白色线框、鼠标、界面截图痕迹、文字、水印及贯穿通道的建筑。

### V3 单幅统一背景（当前运行版本）

- V2 多透明层因生成边缘残留产生矩形堆叠感，停止用于运行时，但保留源文件追溯。
- V3 使用一张 `750 × 1334` 不透明完整绘景，统一透视、光照、笔触和色彩分级，从根源消除拼层边界。
- 整幅背景以 `1.14` 倍超扫，按约 10 秒周期进行 `30 px` 横向、`16 px` 纵向椭圆漂移，并叠加 `±0.008` 呼吸缩放；运动相对角色和障碍肉眼可见，同时不露边。
- GameplayRoot 使用固定 `750 × 1334` 矩形裁剪，背景、障碍、角色、特效和 UI 均不得渲染到游戏区域外。

- 远景：蓝天渐变、阳光、远云海、仙山剪影。
- 中远景：浮岛、南天门、琉璃瓦宫殿、瀑布、仙桥。
- 中景：较大云朵、宫殿侧影、小浮岛、仙鹤。
- 近景：半透明云丝和少量飘叶，只能偶尔经过画面边缘。
- 使用空气透视：越远饱和度与对比度越低，越近越清晰。
- 游戏通道后方降低细节和对比度，避免产生假碰撞边界。

## 7. 障碍物规范

### 山峰

暖黄/赭石岩壁，青绿植被点缀，从下方云海延伸；通道侧轮廓简洁。制作小、中、大三个构图变体，不直接缩放同一张图。

### 石柱

白玉或暖灰天宫石柱，带祥云、莲花或回纹；高度通过模块化柱身或独立变体改变，避免纹理拉伸。

### 火球

金黄核心、橙红火焰、柔和拖尾；运动前有短促收缩/亮起。外焰是表现层，碰撞范围小于视觉范围。

### 乌云

蓝灰/紫灰，边缘柔软但下侧危险轮廓明确。必须与白色背景云区分，可加入旋涡纹和少量紫色电光。

### 雷电

乌云先变暗并闪烁，再出现主闪电。主闪电金白或浅紫，细小电弧只作装饰，不扩大碰撞判定。

### 风火轮

金红轮体、东方纹样、手绘火焰。旋转清楚但不过度频闪；位移轨迹平滑且范围有限。

## 8. UI 规范

- 标题：原创圆润手写字，带轻微毛笔或木刻质感。
- 分数：暖白字 + 深蓝描边，任何背景下均清楚。
- 面板：木牌、云牌、白玉牌或卷轴，造型轻盈。
- 避免大面积厚金边、强发光、金属质感按钮，防止落入传统页游视觉。
- 点击区域大于视觉区域，重要文字不贴屏幕边缘。
- 首页、HUD、暂停、结算只使用必要信息。

## 9. 特效规范

- 飞行：弧形风线、少量云气，不做持续大粒子尾迹。
- 得分：小型金色光点和轻微弹跳。
- 擦边：可选的短促汗滴/风切表现，V1 不作为规则奖励。
- 撞击：云团、星星或帽子歪斜，震屏幅度克制。
- 雷电：预警与生效的颜色、亮度必须明显不同。

## 10. 资源制作与导出

- 先以目标显示尺寸绘制测试，不能只在原画大图上判断细节。
- 透明边缘预留一致，锚点在同一角色动画中保持稳定。
- 同类资源统一光源方向、描边粗细和阴影硬度。
- 输出 PNG；能合图的 UI、角色序列帧和小障碍按模块合图。
- 大背景按实际设备所需尺寸与压缩质量拆分，避免无意义超大透明图。
- 文件名使用小写英文、数字和下划线，例如 `bajie_fly_up_01.png`。

## 11. 美术验收

- 缩放到真机尺寸仍可识别角色表情与障碍类型。
- 背景云与危险乌云不会混淆。
- 碰撞边界与可见主体基本一致。
- 九种组合均能形成清楚的视觉通道。
- 长屏和窄屏裁切后不露空、不遮 HUD。
- 所有资产均为原创或具有明确可商用授权，并保留来源记录。
