# 《飞行小八戒》V1 测试与验收清单

> 2026-09-01 玩法 PIVOT：老板否决长按体验，改为连续点击冲量。新输入与飞行代码已完成并通过浏览器烟雾测试；旧回归见 [10-M1-ACCEPTANCE-REPORT.md](./10-M1-ACCEPTANCE-REPORT.md)，不作为新玩法的十局调参结论。

- [x] M1-1：场景与节点骨架。
- [x] M1-2：连续点击触发单次向上冲量，停止点击后下降。
- [x] M1-2.1：可视化试玩面板与实时遥测。
- [x] M1-3：边界、圆形碰撞体和集中参数。

- [ ] M1-6：点击输入、暂停、后台、重开和 10 局单变量内部回归（待重新执行）。

## 1. 严重级别

- `P0`：崩溃、无法启动、存档破坏、核心流程完全阻塞。
- `P1`：无解障碍、输入失效、碰撞/计分严重错误、无法正常重开、明显性能问题。
- `P2`：表现错误、轻微布局问题、偶现非阻塞异常。
- `P3`：润色建议。

候选发布版必须 `P0 = 0`、`P1 = 0`；P2 需要逐项评估是否接受。

## 2. 核心操作

- [x] 首次点击立即开始并只触发一次向上冲量。
- [x] 持续按住不重复起飞；再次点击才触发下一次冲量。
- [x] 停止点击后持续受重力下落，无残留动力状态。
- [x] 触摸取消与同帧多指点击不会造成持续触发。
- [ ] 微信真机快速连点不漏触发。
- [ ] 卡顿或切后台恢复后不会一帧穿过障碍。
- [ ] 上升和下降速度均不超过配置上限。

## 3. 障碍与计分

- [x] 六类障碍均可生成、移动、碰撞和回收。
- [x] 首批山峰、石柱、乌云可由对象池生成、移动、碰撞和回收。
- [ ] 九种上下配对均经过至少 20 次生成检查。
- [x] 100 个固定种子共 100,000 组自动采样不存在越界、非法间距或高度突变。
- [x] 第一档使用 410～440 px 通道、180 px/s 速度和最大 55 px 相邻高度变化。
- [x] 雷电生效前有 0.70 s 黄色预警，只有 0.32 s 生效阶段开启碰撞。
- [x] 火球与风火轮重用后重新配置运动相位、位置、旋转和碰撞状态。
- [x] 前两组不生成动态危险，动态组后至少插入一组静态组合。
- [x] 动态障碍完整轨迹不进入 240 px 中央安全走廊。
- [x] 上下障碍从第一组开始使用不同振幅、周期和相位独立运动。
- [x] 通道完整进入画面后先显示 0.80 s 双轨迹与极限位置提示。
- [x] 每帧计算有效通道，低于 300 px 前触发双侧向外安全钳制。
- [x] 火球、雷电和风火轮按照实时通道中心与宽度重新定位。
- [x] 生成时将上下完整振幅计入边界校验，不产生越界组合。
- [x] 每组只得 1 分，死亡后停止障碍和计分更新。
- [x] 7 组障碍离屏后复用原节点并重置得分标记、尺寸、类型与通道数据。

## 4. 状态与流程

- [ ] Home、Playing、Paused、GameOver 切换无重复面板。
- [ ] 暂停时玩家、障碍、动态动画、计分全部停止。
- [ ] 回到前台保持暂停，由玩家主动继续。
- [ ] 连续重开 50 次不出现速度、分数或障碍残留。
- [ ] 死亡动画期间不能重复触发结算。
- [ ] 返回首页再开始时使用全新单局状态。

## 5. 存储与音频

- [ ] 正常保存并读取最高分。
- [ ] 存储为空、字段缺失、内容损坏时使用默认值。
- [ ] 新分数未超过最高分时不覆盖错误值。
- [ ] 音乐和音效开关分别生效并跨启动保存。
- [ ] 切后台停止音频，返回后不会叠加播放多个 BGM。
- [x] 已实现 Master、Music、SFX 逻辑增益分组及前后台暂停保护。
- [ ] 耳机和手机扬声器下，仅播放 BGM、得分和碰撞音效；点击与雷电无音效。
- [ ] BGM 循环无明显爆音或重复叠加。

## 6. 视觉与适配

- [ ] 常见 `16:9`、`19.5:9`、`20:9` 竖屏不露空、不裁切核心玩法区。
- [ ] 刘海、挖孔和圆角设备的 HUD/按钮位于安全区。
- [ ] 危险乌云与背景白云能在一眼内区分。
- [ ] 玩家碰撞体与视觉主体一致，耳朵外缘不会造成明显冤死。
- [ ] 动态障碍预警状态与生效状态差异明确。
- [ ] 背景不形成类似障碍的假轮廓。
- [ ] 所有文字清晰，无缺字、乱码、错误换行。

## 7. 性能与稳定性

- [ ] 微信开发者工具无持续报错和未处理异常。
- [ ] 至少一台中档真机完成 10 分钟连续游玩。
- [ ] 长时间游玩节点数量趋于稳定，不持续增长。
- [x] 代码审查确认运行期只复用 7 组预热节点，不在 update 中创建或销毁障碍。
- [ ] 无肉眼明显周期卡顿；大量透明云和粒子时仍稳定。
- [ ] 首屏加载时间、包体和纹理内存记录在发布检查表中。
- [ ] Debug 日志、碰撞框和测试按钮在发布构建中关闭。

## 10. 最终验收场景

由未参与开发的测试者完成：首次打开游戏，不接受口头指导，开始一局、获得至少 1 分、故意失败、查看最高分、重新开始、暂停并恢复。若测试者无法理解连续点击/停止点击操作，或任一步骤被阻塞，则 V1 不通过验收。
