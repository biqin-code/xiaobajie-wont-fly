# 飞行小八戒

微信小游戏项目，使用 Cocos Creator 3.8.8（3.8 LTS）与 TypeScript 开发。

## 工程信息

- 项目显示名：飞行小八戒
- 技术包名：`flying-bajie`
- Cocos Creator：`3.8.8`
- 项目类型：2D
- 设计分辨率：`750 × 1334`，竖屏
- 目标平台：微信小游戏

## 打开工程

1. 启动 Cocos Creator 3.8.8。
2. 在项目管理器中选择“导入”。
3. 选择本目录作为项目目录。
4. 首次打开时等待 Creator 完成资源导入并生成 `library/`、`temp/` 和 `local/`。

不要提交或手工修改上述三个生成目录。美术源图保存在 `art_source/`，运行资源保存在 `assets/`。

## 当前阶段

当前只完成 M0 的工程基础结构。尚未实现玩家飞行、障碍、计分、UI 或微信平台逻辑。

详细目录职责见 [项目结构说明](./docs/v1/09-PROJECT-STRUCTURE.md)。
