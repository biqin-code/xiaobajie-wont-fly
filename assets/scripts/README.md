# 脚本目录职责

- `app/`：启动流程、全局状态机和生命周期协调。
- `gameplay/`：玩家飞行、障碍、碰撞、计分和难度规则。
- `input/`：把触摸和鼠标事件转换为稳定的玩法动作状态。
- `systems/`：对象池、音频、存储和时间等可复用服务。
- `platform/`：浏览器与微信小游戏平台适配；业务代码不得直接散落 `wx.*` 调用。
- `config/`：工程常量、玩法数值和数据结构。
- `ui/`：首页、HUD、暂停和结算组件。
- `utils/`：无业务状态的通用工具。

依赖方向应保持为“表现层 → 业务接口 → 纯逻辑/配置”，禁止通过节点名称全局搜索来连接模块。
